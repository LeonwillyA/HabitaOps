HabitaOps será una plataforma para digitalizar la administración de condominios,
permitiendo gestionar unidades inmobiliarias, propietarios, recibos y comprobantes.

La primera versión permitirá:

- Registrar condominios
- Registrar edificios
- Gestionar departamentos y cocheras
- Asociar propietarios
- Generar recibos
- Registrar comprobantes
